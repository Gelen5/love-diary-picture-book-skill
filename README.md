# Love Diary Picture Book Skill

把用户提供的聊天记录和照片，整理成一套有时间线、有真实对话、有统一人物形象的 Q 版恋爱绘本。

默认输出：

- 3:4 竖版绘本图片
- 可打印的 PDF
- 项目过程中的人物设定、时间线和页面证明稿

默认不制作互动网页、翻页网页或二维码页面。需要网页时，应由用户单独提出。

## 适合什么场景

- 七夕、生日、纪念日礼物
- 恋爱、订婚、结婚、生子时间线记录
- 把聊天记录做成长期保存的家庭纪念册
- 根据真实照片制作统一的 Q 版人物

## 用户需要提供

至少提供以下内容：

1. 聊天记录 TXT、CSV、JSON、Markdown、截图，或手动整理的聊天原文
2. 需要出现在绘本中的人物照片
3. 已知的重要日期和事件
4. 对画风、比例、服装、书名的偏好

聊天记录不要求全部可读。无法读取、无法确认或看不清的内容要标记出来，不能猜测补写。

## 制作流程

Skill 会分四次让用户确认，不会一开始就批量生成整本绘本。

### 第一步：人物设定

根据照片整理人物的脸型、发型、表情、身材比例、服装风格和 Q 版视觉方向，同时确定画面比例和不同阶段的服装变化。

用户确认人物形象后，才进入故事整理。

### 第二步：时间线和聊天筛选

按照以下顺序整理故事：

> 第一次联系 → 慢慢靠近 → 约会恋爱 → 矛盾与和好 → 订婚 → 领证 → 婚礼 → 怀孕 → 生子 → 一家人的日常

每个节点都会保留：

- 精确日期
- 事件名称
- 原始聊天原话
- 说话人
- 画面设想
- 对应服装和场景

用户确认日期、原话和故事顺序后，才开始生成图片。

### 第三步：三张试做图

先制作三张不同阶段的图片：

1. 开始认识或第一句聊天
2. 恋爱、矛盾或关系变化
3. 结婚、生子或家庭日常

用户重点检查人物像不像、比例是否舒服、服装是否合适、画面是否留出了文字空间。

### 第四步：完整证明稿

试做图确认后，才批量生成其余页面并排版 PDF。用户需要逐页检查：

- 日期
- 聊天文字
- 人物和说话方向
- 页面顺序
- 图片与文字是否重叠
- 是否有空白或不完整页面

确认后输出最终 PDF。

## 设计原则

- 默认使用 3:4 竖版比例，适合手机查看和绘本排版
- 每一页聚焦一个情绪或故事节点
- 不强制每页使用三个横向场景
- 聊天文字优先在排版阶段添加，不依赖图片模型生成中文
- 重要日期精确到天，不擅自修改用户确认的日期
- 不只保留“我爱你”，也保留约会、等待、争吵、和好、吃饭和照顾孩子等普通内容
- 通过不同阶段更换衣服和场景，保持人物一致但避免每页穿同一套衣服

## 隐私和安全边界

- 只处理用户主动提供的聊天记录和照片
- 不破解微信数据库、不提取密钥、不绕过登录或安全限制
- 不从网络搜索替代人物照片或推断人物身份
- 默认不把完整聊天记录放入最终公开文件
- 自动避开手机号、地址、密码、财务信息和不适合公开的隐私内容

- [`references/project-schema.md`](references/project-schema.md)

## 交付前检查

最终交付前必须检查：

- PDF 能正常打开
- 页数和顺序正确
- 所有图片引用完整
- 日期没有错位
- 聊天文字没有重叠或裁切
- 人物形象前后一致
- 没有意外空白页
- 手机和打印尺寸下都能读清文字
