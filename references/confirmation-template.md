# Confirmation templates

Use these short prompts at the four gates. Replace bracketed fields with the current project details.

## Gate 1

已整理好人物设定和视觉方向，请确认：

- 男主：[…]
- 女主：[…]
- 孩子：[…]
- 画风和比例：[…]
- 服装变化：[…]

确认后我再生成绘本试做页。

## Gate 2

已按时间整理出故事线，共 [… ] 个节点、[… ] 条候选聊天原话。请重点核对日期、人物称呼和是否保留矛盾/孕期/出生后的内容。确认后进入三张试做图。

## Gate 3

三张试做图已完成，请只检查人物像不像、比例是否舒服、衣服是否合适、聊天文字是否压住画面。确认后再批量生成。

## Gate 4

完整绘本证明稿已完成，请逐页检查日期、文字、顺序和是否有空白页。确认后输出最终PDF。
